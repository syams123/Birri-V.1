ISTIQAMAH — Mobile reference edition
1. Extract the ZIP, keeping all folders together.
2. Open index.html for local preview, or run python -m http.server 8000 from this folder and open http://localhost:8000.
3. For installation on Android/iOS, deploy the entire folder to HTTPS hosting. Use browser Add to Home Screen / Install.
4. Configure Firebase in Profile; enable Google authentication and authorize your hosting domain. No Firestore synchronization is implemented. Progress is local to the browser.
5. Quran and hadith readers require network access. Hadith translation is English. Video export depends on browser support.
6. This is a PWA source project, not an APK or IPA. Browser rendering tests were blocked by environment policy; JavaScript syntax checks passed. Pixel-perfect fidelity and device installation have not been verified.
